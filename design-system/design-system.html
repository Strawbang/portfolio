Voix & Marque

Le positionnement issu du portfolio et de LinkedIn : Full-Stack Software Engineer, TypeScript / React / Node.js / DevOps / Rust / AI-GenAI, basé à Paris.

Technique & concret

Des résultats mesurables (« temps de création produit réduit de 80% »), pas de jargon creux.

Pragmatique

Les compromis sont explicités — EC2 vs Bedrock, terminal vs IDE. On assume les choix.

Curieux & builder

Open source (rustkit-ai), articles de blog, exploration continue de l'IA/GenAI.

Accessible

Bilingue FR/EN, ton direct à la première personne, orienté collaboration.

✓ À faire
  • Utiliser le dégradé accent avec parcimonie, comme point focal.
  • Dark-first : fond --gray-999, texte --gray-200.
  • Rubik pour les titres, Public Sans pour le corps.
  • Formes en pilule (999rem) pour actions et badges.
✕ À éviter
  • Multiplier les couleurs d'accent hors de la gamme violette.
  • Mélanger les rayons (cartes 0.5rem, pas de coins durs aléatoires).
  • Titres en Public Sans ou corps en Rubik.
  • Ombres lourdes — l'élévation reste subtile.
